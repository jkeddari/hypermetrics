## Data Export

**Available on:** Basic and Pro plans

Export your watchlist and transaction data in multiple formats for custom analysis, record keeping, or use in other tools.

## What Can You Export?

### Watchlist Data
- All tracked addresses with labels
- Alert configurations
- Performance metrics
- Historical data (based on your plan limits)

### Transaction Data
- Complete transaction history for tracked addresses
- Large transaction feed
- Custom filtered data sets

### Analytics Data
- Performance summaries
- PnL reports
- Volume statistics
- Custom metrics

## Export Formats

### CSV (Comma-Separated Values)
Perfect for:
- Excel analysis
- Google Sheets
- Custom spreadsheets
- Data science tools (pandas, R, etc.)

### JSON (JavaScript Object Notation)
Perfect for:
- API integrations
- Custom applications
- Database imports
- Programming analysis

## How to Export

### Export Watchlist

1. Go to **Watchlist** page
2. Click **"Export"** button
3. Choose format (CSV or JSON)
4. Select data range:
   - Last 24 hours
   - Last 7 days
   - Last 30 days (Pro)
   - All time (Pro only)
5. Click **"Download"**

### Export Transactions

1. Go to **Large Transactions** or an address detail page
2. Click **"Export"** button
3. Choose format and timeframe
4. Apply filters if needed
5. Click **"Download"**

## Export Limits

### Basic Plan
- 30 days of historical data
- Up to 10,000 rows per export
- 5 exports per day

### Pro Plan
- Unlimited historical data
- Up to 100,000 rows per export
- Unlimited exports

## Tips

Export your data regularly to maintain your own records independent of the platform.

### Use Appropriate Formats
- **CSV** for human-readable spreadsheets

Apply filters to export only the data you need, reducing file size and processing time.

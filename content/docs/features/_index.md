## Core Features

Hypermetrics provides everything you need to monitor Hyperliquid activity and make informed trading decisions.

### Leaderboard Tracking
Monitor top performers on Hyperliquid with real-time rankings. Track PnL, volume, ROI, and win rates across multiple timeframes.

### Address Analytics
Deep dive into any wallet address with comprehensive trading history, position tracking, and performance metrics.

### Large Transaction Feed
Real-time feed of significant on-chain movements. Never miss a whale transaction or major market move.

### Custom Alerts
Set up personalized alerts for wallet activity, transaction thresholds, and custom conditions. Get notified via email, push, or webhooks.

### Real-time Data
Sub-100ms latency for all metrics. Our infrastructure connects directly to Hyperliquid for instant updates.

### Data Export
Export your tracked data in CSV or JSON formats (Basic/Pro plans). Perfect for custom analysis and record keeping.
